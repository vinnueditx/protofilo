# Personal Portfolio Website

A clean, responsive, and modern developer portfolio built using pure **HTML5**, **CSS3**, and **vanilla JavaScript**. It includes dynamic typing text, smooth scrolling, active section tracking, scroll-triggered animations, and a dark neon theme.
